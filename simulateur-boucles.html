🔁 Boucle for

                    

                        
Structure : for (init; condition; increment)

                        
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
// Affiche 1, 2, 3, 4, 5

                    

                    

                        
Calculer une somme

                        
let somme = 0;
for (let i = 1; i <= 10; i++) {
    somme += i;
}
console.log(somme); // 55

                    

                    

                        
Parcourir un tableau par index

                        
const fruits = ["pomme", "kiwi"];
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

                    

                    

                        💡 i++ ajoute 1 a chaque tour. La boucle s'arrete quand la condition devient fausse.
                    

                

            


            
            

                

                    
🔄 Boucle while

                    

                        
Tant que la condition est vraie

                        
let i = 1;
while (i <= 5) {
    console.log(i);
    i++;
}

                    

                    

                        
Compte a rebours

                        
let i = 5;
while (i >= 1) {
    console.log(i);
    i--;
}
// 5, 4, 3, 2, 1

                    

                    

                        ⚠ N'oubliez pas de faire evoluer la variable (i++ ou i--), sinon la boucle tourne a l'infini !
                    

                

            


            
            

                

                    
📋 Boucle for...of

                    

                        
Parcourir directement les valeurs

                        
const fruits = ["pomme", "banane", "orange"];
for (const fruit of fruits) {
    console.log(fruit);
}

                    

                    

                        
Additionner les valeurs d'un tableau

                        
const nombres = [10, 20, 30];
let total = 0;
for (const n of nombres) {
    total += n;
}
console.log(total); // 60

                    

                    

                        💡 for...of donne directement la VALEUR (pas l'index). Ideal pour parcourir un tableau simplement.
                    

                

            


            
            

                

                    
🛑 break & continue

                    

                        
break : arreter la boucle

                        
for (let i = 1; i <= 10; i++) {
    if (i === 4) break;
    console.log(i);
}
// 1, 2, 3 (s'arrete a 4)

                    

                    

                        
continue : passer au tour suivant

                        
for (let i = 1; i <= 5; i++) {
    if (i === 3) continue;
    console.log(i);
}
// 1, 2, 4, 5 (saute le 3)

                    

                    

                        💡 break sort completement de la boucle ; continue saute seulement l'iteration en cours.
