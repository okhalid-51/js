📚 Aide Modifier un texte

                
            

            
textContent · innerHTML

        


        

            
            

                
                
                
            


            
            

                

                    
📝 textContent : changer le texte

                    

                        
Remplacer le texte d'un element

                        
const titre = document.getElementById("titre");
titre.textContent = "Nouveau titre";

                    

                    

                        
Vider le contenu

                        
document.getElementById("boite").textContent = "";

                    

                    

                        
Lire le texte affiche

                        
console.log(document.getElementById("titre").textContent);

                    

                    

                        💡 textContent = "..." remplace le texte affiche. Les balises HTML ne sont PAS interpretees : elles apparaissent telles quelles.
                    

                

            


            
            

                

                    
🏷 innerHTML : inserer du HTML

                    

                        
Mettre du texte en gras

                        
document.getElementById("boite").innerHTML = "<strong>Important</strong>";

                    

                    

                        
Inserer une liste

                        
document.getElementById("boite").innerHTML = "<ul><li>Pomme</li></ul>";

                    

                    

                        💡 innerHTML interprete les balises HTML : <strong> met en gras, <em> en italique, <ul>/<li> cree une liste.
                    

                

            


            
            

                

                    
⚖ Différence textContent / innerHTML

                    

                        
textContent : texte brut

                        
el.textContent = "<b>test</b>";
// Affiche litteralement : <b>test</b>

                    

                    

                        
innerHTML : interprete le HTML

                        
el.innerHTML = "<b>test</b>";
// Affiche : test (en gras)

                    

                    

                        💡 Memo : textContent n'interprete PAS les balises (texte brut). innerHTML les interprete (HTML reel). Utilisez textContent pour du texte simple, innerHTML uniquement quand vous avez besoin de balises.
