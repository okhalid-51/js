➕ Opérateurs arithmétiques

                    

                        
Les quatre opérations + le modulo

                        
console.log(5 + 3);   // 8  (addition)
console.log(10 - 4);  // 6  (soustraction)
console.log(6 * 7);   // 42 (multiplication)
console.log(20 / 4);  // 5  (division)
console.log(17 % 5);  // 2  (reste / modulo)

                    

                    

                        💡 Le modulo % donne le RESTE d'une division. 17 = 3*5 + 2, donc 17 % 5 vaut 2.
                    

                

            


            
            

                

                    
⚖ Opérateurs de comparaison

                    

                        
Renvoient true ou false

                        
console.log(5 === 5);  // true  (egal valeur ET type)
console.log(5 !== 3);  // true  (different)
console.log(10 > 3);   // true  (superieur)
console.log(3 >= 3);   // true  (superieur ou egal)
console.log(2 < 1);    // false (inferieur)

                    

                    

                        💡 Utilisez toujours === (et non ==) pour comparer valeur ET type.
                    

                

            


            
            

                

                    
🔗 Opérateurs logiques

                    

                        
ET && / OU || / NON !

                        
console.log(true && false); // false (ET : les deux vrais)
console.log(true || false); // true  (OU : au moins un vrai)
console.log(!true);         // false (NON : inverse)

                    

                    

                        💡 && est vrai seulement si LES DEUX le sont. || est vrai si AU MOINS un l'est. ! inverse la valeur.
                    

                

            


            
            

                

                    
✍ Opérateurs d'affectation

                    

                        
Raccourcis d'affectation

                        
let total = 10;
total += 5;  // total = total + 5  -> 15
total -= 2;  // total = total - 2  -> 13
total *= 2;  // total = total * 2  -> 26
console.log(total);

                    

                    

                        💡 total += 5 est un raccourci pour total = total + 5.
