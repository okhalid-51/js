📤 submit & preventDefault

                    

                        
Exemple de la diapo

                        
const form = document.getElementById("formulaire");
form.addEventListener("submit", (event) => {
    event.preventDefault();
    console.log("Formulaire soumis");
});

                    

                    

                        💡 Sans preventDefault(), la page se recharge a chaque envoi et le JavaScript n'a pas le temps de traiter les donnees.
                    

                

            


            
            

                

                    
⌨ Recuperer la saisie

                    

                        
input.value

                        
const nom = document.getElementById("nom").value;
console.log(nom);

                    

                    

                        
Plusieurs champs

                        
const nom = document.getElementById("nom").value;
const email = document.getElementById("email").value;
console.log(nom, email);

                    

                    

                        💡 .value renvoie TOUJOURS une chaine de caracteres (string), meme pour un champ de type number. Utilisez Number(...) pour comparer des nombres.
                    

                

            


            
            

                

                    
✅ Validation simple

                    

                        
Champ obligatoire

                        
if (nom === "") {
    console.log("Le nom est obligatoire");
}

                    

                    

                        
Longueur minimale

                        
if (mdp.length < 6) {
    console.log("Mot de passe trop court");
}

                    

                    

                        
Email valide (contient @)

                        
if (!email.includes("@")) {
    console.log("Email invalide");
}

                    

                    

                        💡 .trim() enleve les espaces au debut et a la fin : pratique pour empecher une saisie composee uniquement d'espaces.
                    

                

            


            
            

                

                    
🧩 Tout assembler

                    

                        
Formulaire valide

                        
form.addEventListener("submit", (e) => {
    e.preventDefault();
    const nom = document.getElementById("nom").value;
    const email = document.getElementById("email").value;
    if (nom !== "" && email.includes("@")) {
        console.log("Bienvenue " + nom);
    } else {
        console.log("Formulaire invalide");
    }
});

                    

                    

                        💡 On combine submit + preventDefault + lecture des valeurs + validation. C'est le coeur du traitement d'un formulaire en JavaScript.
