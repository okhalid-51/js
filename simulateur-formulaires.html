📤 submit & preventDefault

                    

                        
Exemple de la diapo

                        
const form = document.getElementById("formulaire");
form.addEventListener("submit", (event) => {
    event.preventDefault();
    document.getElementById("message").textContent = "Formulaire soumis";
});

                    

                    

                        💡 On ecrit le resultat dans la balise <p id="message"> avec .textContent. Sans preventDefault(), la page se recharge a chaque envoi et le JavaScript n'a pas le temps de traiter les donnees.
                    

                

            


            
            

                

                    
⌨ Recuperer la saisie

                    

                        
input.value → #message

                        
const nom = document.getElementById("nom").value;
document.getElementById("message").textContent = nom;

                    

                    

                        
Plusieurs champs

                        
const nom = document.getElementById("nom").value;
const email = document.getElementById("email").value;
document.getElementById("message").textContent = nom + " " + email;

                    

                    

                        💡 .value renvoie TOUJOURS une chaine de caracteres (string), meme pour un champ de type number. Utilisez Number(...) pour comparer des nombres.
                    

                

            


            
            

                

                    
✅ Une erreur SOUS chaque champ

                    

                        
Champ obligatoire → #erreur-nom

                        
if (nom === "") {
    document.getElementById("erreur-nom").textContent = "Le nom est obligatoire";
}

                    

                    

                        
Mot de passe trop court

                        
if (mdp.length < 6) {
    document.getElementById("erreur-motdepasse").textContent = "6 caracteres minimum";
}

                    

                    

                        
Penser a VIDER l'erreur si tout est bon

                        
else {
    document.getElementById("erreur-nom").textContent = "";
}

                    

                    

                        💡 Chaque champ a sa zone d'erreur #erreur-NOMDUCHAMP. On y ecrit le message en cas de probleme, et on la VIDE ("") quand la saisie est correcte (comme un vrai formulaire).
                    

                

            


            
            

                

                    
🧩 Tout assembler

                    

                        
Plusieurs champs + drapeau "ok"

                        
form.addEventListener("submit", (e) => {
    e.preventDefault();
    const nom = document.getElementById("nom").value;
    const email = document.getElementById("email").value;
    // on vide d'abord les erreurs
    document.getElementById("erreur-nom").textContent = "";
    document.getElementById("erreur-email").textContent = "";
    let ok = true;
    if (nom === "") {
        document.getElementById("erreur-nom").textContent = "Nom obligatoire";
        ok = false;
    }
    if (!email.includes("@")) {
        document.getElementById("erreur-email").textContent = "Email invalide";
        ok = false;
    }
    if (ok) {
        document.getElementById("message").textContent = "Inscription reussie";
    }
});

                    

                    

                        💡 Le drapeau ok reste vrai seulement si AUCUNE erreur n'a ete trouvee. On affiche le succes dans #message uniquement quand ok est vrai. Pour un calcul (age, moyenne, equation), on utilise Number(...) pour convertir la saisie en nombre.
