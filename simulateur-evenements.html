📚 Aide Evenements

                
            

            
addEventListener · click / input / change / submit

        


        

            
            

                
                
                
                
            


            
            

                

                    
🖱 Réagir au clic

                    

                        
addEventListener("click", ...)

                        
const btn = document.getElementById("btn");
btn.addEventListener("click", () => {
    console.log("Bouton clique !");
});

                    

                    

                        
Exemple de la diapo : alert

                        
btn.addEventListener("click", () => {
    alert("Clique !");
});

                    

                    

                        💡 addEventListener(type, fonction) : le 1er argument est le NOM de l'evenement, le 2eme la fonction a executer.
                    

                

            


            
            

                

                    
⌨ input & change

                    

                        
input : a chaque frappe

                        
const champ = document.getElementById("champ");
champ.addEventListener("input", (e) => {
    console.log(e.target.value);
});

                    

                    

                        
change : quand la valeur change (liste)

                        
const liste = document.getElementById("liste");
liste.addEventListener("change", (e) => {
    console.log(e.target.value);
});

                    

                    

                        💡 input se declenche a CHAQUE caractere tape. change se declenche quand on quitte le champ ou qu'on choisit une option.
                    

                

            


            
            

                

                    
📤 Formulaire : submit

                    

                        
Empecher le rechargement

                        
const form = document.getElementById("formulaire");
form.addEventListener("submit", (e) => {
    e.preventDefault();
    console.log("Formulaire envoye");
});

                    

                    

                        💡 e.preventDefault() empeche le comportement par defaut (ici : recharger la page). Indispensable pour traiter un formulaire en JS.
                    

                

            


            
            

                

                    
📦 L'objet event

                    

                        
event.target : l'element vise

                        
btn.addEventListener("click", (e) => {
    console.log(e.target.textContent);
});

                    

                    

                        
event.type : le nom de l'evenement

                        
btn.addEventListener("click", (e) => {
    console.log(e.type); // "click"
});

                    

                    

                        💡 La fonction recoit automatiquement un objet "event" (souvent nomme e). Il decrit ce qui s'est passe : e.target, e.type, e.target.value...
